Einstellungen

Speichern einrichten (GitHub-Token)

Deine Einträge werden als Datei data/ernaehrung.csv direkt in dein GitHub-Repo geschrieben. Dafür braucht diese Seite einmalig pro Gerät einen Token, der nur auf dieses eine Repo schreiben darf. Er bleibt nur in diesem Browser gespeichert.

Am schnellsten über diesen vorausgefüllten Link (dann nur noch Schritt 3 und 5). Oder von Hand:

  1. Auf github.com: Profilbild → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Name z. B. „Ernährung Dashboard“, Ablauf nach Wunsch (z. B. 1 Jahr)
  3. Repository access: „Only select repositories“ → Garmin auswählen
  4. Bei Permissions auf „+ Add permissions“ klicken, Contents anhaken, dann daneben von „Read-only“ auf „Read and write“ umstellen
  5. Generate token, Token kopieren und hier einfügen
So wird gerechnet: Dein Umsatz = Ø gegessene Kalorien − Gewichtsveränderung × 7.700 kcal/kg, über den gewählten Zeitraum. Die Gewichtsveränderung kommt aus einer Ausgleichsgeraden durch alle Wiegungen im Zeitraum, damit einzelne Ausreißer (Wasser, Salz, Kohlenhydrate) kaum ins Gewicht fallen. Ab 7 Tagen mit Daten gibt es einen vorläufigen Wert, ab 14 Tagen einen belastbaren. Garmin-Werte werden täglich um ca. 6 Uhr automatisch übernommen (immer bis gestern). Hinweis: Das Repo und diese Seite sind öffentlich – die Werte sind für jeden mit dem Link sichtbar.
